## How to run locally
- **Backend:** `cd backend && uv run uvicorn app.main:create_app --factory --port 8001`. Port 8000 belongs to the user's founder-intel server; don't kill it.
- **Frontend:** `cd frontend && NEXT_PUBLIC_API_URL=http://localhost:8001 npm run dev` (port 3000).
- **Screenshot helper:** run it from PowerShell, because Git Bash mangles `/paths`: `node <scratchpad>\shoot.mjs brand /brand/money out.png 8000`. It logs in through `/api/demo-login`.
- **Env:**
  - Both `.env` files (`backend/.env`, `frontend/.env.local`) are git-ignored and already hold the PayPal sandbox, Anthropic and AG Studio values, with `HACKATHON_MODE=1`.
  - The source copy is `D:\Github\All-Hackathons\Paypal-oct2026\.env`. Never print secrets.
- **Tests:** they hit hosted Supabase and are slow, so run only the files you need, with `-p no:cacheprovider -q`. The `funded` fixture resets `usage_counters`.
- **Shell gotcha:** a bash heredoc containing `!=` breaks the Bash tool. Write the Python patch to a file with the Write tool and run it.
